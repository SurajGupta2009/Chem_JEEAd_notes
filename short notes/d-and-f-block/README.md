| **12** | `DF-12` | **Potassium Dichromate: Acidic Redox & Chromyl Chloride Test** | Half-reaction Cr₂O₇²⁻ + 14 H⁺ + 6 e⁻ → 2 Cr³⁺ + 7 H₂O (Eq Wt = M/6 = 49.03), oxidations: Fe²⁺→Fe³⁺, I⁻→I₂, H₂S→S, SO₃²⁻→SO₄²⁻, Sn²⁺→Sn⁴⁺; Chromyl chloride test: solid Cl⁻ + K₂Cr₂O₇ + conc H₂SO₄ → CrO₂Cl₂ (deep red vapor) → NaOH (yellow Na₂CrO₄) → Pb(AcO)₂ (bright yellow PbCrO₄↓), exceptions (Hg₂Cl₂, HgCl₂, AgCl, PbCl₂, SnCl₂); Butterfly peroxide CrO₅ in ether (Cr +6). |
