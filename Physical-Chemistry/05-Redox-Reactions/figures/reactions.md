# Redox reaction gallery — disproportionation

[← Full explanation, oxidation states and NCERT references](../notes.md#d-disproportionation-the--of-jee)

### Hydrogen peroxide
$$\ce{2H2O2 -> 2H2O + O2}$$
O: −1 → −2 and 0.

### Phosphorus in alkali
$$\ce{P4 + 3OH^- + 3H2O -> PH3 + 3H2PO2^-}$$
P: 0 → −3 and +1. NCERT eq. 7.46.

### Sulphur in alkali
$$\ce{S8 + 12OH^- -> 4S^2- + 2S2O3^2- + 6H2O}$$
S: 0 → −2 and +2 (average in thiosulphate). NCERT eq. 7.47.

### Chlorine in cold alkali
$$\ce{Cl2 + 2OH^- -> Cl^- + ClO^- + H2O}$$
Cl: 0 → −1 and +1. NCERT eq. 7.48.

### Chlorine in hot alkali
$$\ce{3Cl2 + 6OH^- -> 5Cl^- + ClO3^- + 3H2O}$$
Cl: 0 → −1 and +5.

### Hypochlorite on standing or heating
$$\ce{3ClO^- -> ClO3^- + 2Cl^-}$$
Cl: +1 → +5 and −1.

### Chlorate
$$\ce{4ClO3^- -> Cl^- + 3ClO4^-}$$
Cl: +5 → −1 and +7. NCERT Problem 7.5.

### Copper(I)
$$\ce{2Cu^+ -> Cu^2+ + Cu}$$
Cu: +1 → +2 and 0.

### Manganate(VI) in acid
$$\ce{3MnO4^2- + 4H^+ -> 2MnO4^- + MnO2 + 2H2O}$$
Mn: +6 → +7 and +4.

### Manganese(III)
$$\ce{2Mn^3+ + 2H2O -> Mn^2+ + MnO2 + 4H^+}$$
Mn: +3 → +2 and +4. NCERT Ex. 7.21.

### Nitrogen dioxide in alkali
$$\ce{2NO2 + 2OH^- -> NO2^- + NO3^- + H2O}$$
N: +4 → +3 and +5. NCERT Problem 7.6.

### Nitrogen dioxide in water
$$\ce{3NO2 + H2O -> 2HNO3 + NO}$$
N: +4 → +5 and +2.

### Chlorine dioxide in alkali
$$\ce{2ClO2 + 2OH^- -> ClO2^- + ClO3^- + H2O}$$
Cl: +4 → +3 and +5.

### Cyanogen in alkali
$$\ce{(CN)2 + 2OH^- -> CN^- + CNO^- + H2O}$$
C: +3 → +2 and +4. NCERT Ex. 7.20.
